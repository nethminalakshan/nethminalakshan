### 🎯 About Me

I'm a **Computer Engineering undergraduate** at the **University of Ruhuna, Sri Lanka**, currently working as an **IoT Intern at SLT PLC**, where I build and maintain real industrial monitoring systems — not tutorial projects.

My day-to-day work involves getting hardware, serial protocols, and databases to actually talk to each other reliably in the field:

- ⚡ **Industrial monitoring** — power analyzers, diesel generator controllers, and RS-485 buses running 24/7
- 🍓 **Raspberry Pi automation** — migrating legacy Node-RED flows into standalone Python services
- 📡 **Modbus RTU/TCP** — register-level debugging, block reads, word-swap float decoding
- 🗄️ **Time-series data** — InfluxDB v2 pipelines from edge devices to dashboards
